# LeanGUI

---

A gui wrapper for leandvb. Mostly vibe-coded, but I'll try to unvibe code it in the future.

## Dependencies

---

### Python Libraries

1. numpy
  
2. PySide6
  
3. pyqtgraph
  

### Binaries

1. leandvb
  
2. ldpc_tool
  
3. mpv
  

leandvb and ldpctool are expected to be in the same directory as gui.py. They can be compiled using instruction on the respective [project site](https://www.pabr.org/radio/leandvb/leandvb.en.html)

## Usage

---

```bash
$ python3 gui.py
```
